# 專案知識庫與筆記目錄 (Knowledge Base)

本目錄存放「用 Agent 來學習 Agent」的所有結構化研究筆記、架構分析與專題討論。

---

## 目錄分區規劃

- **`01-foundations/`**：Phase 1 - Agent 核心基石
  - Agent 定義、自主性維度、感知（Perception）、規劃（Planning）、記憶（Memory）、工具行動（Tools/Actions）
- **`02-patterns/`**：Phase 2 - 設計模式與推論架構
  - ReAct、Plan-and-Solve、Reflexion、Multi-Agent（協作、階層、辯論模式）
- **`03-frameworks/`**：Phase 3 - 主流框架評估與對比
  - LangGraph、AutoGen、CrewAI、Antigravity 原生 Agent 等
- **`04-protocols/`**：Phase 4 - 工具鏈、協定與擴展
  - Model Context Protocol (MCP)、HITL (Human-in-the-loop)、安全性與權限邊界
- **`05-synthesis/`**：Phase 5 - 綜合實踐與經驗總結
  - Prompt 模板庫、決策指南、踩坑整理

---

## 筆記撰寫建議格式

每個專題筆記建議具備：
1. **核心概念與定義**（一句話本質）
2. **架構或流程圖**（Mermaid 圖表）
3. **關鍵機制與運作原理**
4. **優缺點與適用場景**
5. **與 Agent 協同討論出的關鍵洞察 (Insights)**
